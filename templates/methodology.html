Methodology

How it works

A preliminary assessment. Nothing here proves an image real or fake.

01Validation

Allowed type, size limit and a full decode. Stored under a random name; never executed.

02SHA-256 fingerprint

Hash of the exact bytes received, re-checked whenever the report opens.

Starts at upload; does not prove the file's earlier history.

03Metadata

EXIF, GPS, embedded text and C2PA/XMP markers. Missing metadata is not evidence of manipulation.

05Model certaintyshown as "Confidence"

The detector's highest class score for its prediction (its softmax output), shown exactly as stored with the result. For the two-class model this is the larger of the AI-generated and real-image scores.

{{ certainty.CERTAINTY_NOTE }}

  • Not a probability of being correct and not an AI-generated probability. Never combined with the heuristic caution score.
  • Unchanged by the verdict: an Inconclusive result shows the same certainty the model produced.
  • If the evaluated model and revision match, the result also shows how often test-split predictions in the same certainty band ({% for lo, hi in certainty.BINS %}{{ (lo * 100)|int }}–{{ (hi * 100)|int }}%{{ ', ' if not loop.last }}{% endfor %}) were correct. Shown only when the band has at least {{ certainty.MIN_BIN_N }} test images; never estimated.
  • The test split is small and 20 of its 40 real images are processed copies (resized, screenshot, messaging-app) of the other 20, so those images are not independent. Every evaluation score of the current model was below 5% or above 95%, so in practice only the 90–100% band has data.
  • Not shown when AI analysis is unavailable, for models whose output is not a mapped softmax, or for reports created before this field existed.
